# KAI Cloud 账户注销说明

版本：1.0  
适用对象：企业采购方、企业供应商及授权经办人

## App 内入口

1. 登录 KAI Cloud；
2. 进入“账户与合规”；
3. 选择“账户注销”；
4. 阅读影响范围并完成身份验证；
5. 提交注销申请；
6. 在注销状态页查看处理结果或取消尚未进入最终执行阶段的申请。

## 网页入口

公开网页：`[https://正式域名/account-deletion.html]`

网页必须无需重新安装 App 即可访问，并清楚显示 KAI Cloud 或运营主体名称、申请方式、处理步骤和联系方式。

## 注销前检查

以下事项可能需要先处理：

- 未完成订单、交付或验收；
- 退款、拒付或争议；
- 未开具或待红冲发票；
- 待结算、分账或赔付；
- 容量预留、锁定、交付中或风控冻结；
- 企业账户授权关系或法定保存义务。

## 注销结果

- 账户登录能力关闭；
- 公开身份和无继续保存必要的账户信息删除或匿名化；
- 依法需要保留的订单、支付、计量、发票、结算、风控和审计记录继续受限保存；
- 注销不等于删除依法必须保存的企业交易凭证；
- 处理完成后通过 `[短信/邮箱，待选择]` 通知申请人。
