## 3. 一句话业务说明

面向企业采购方和企业供应商的 GPU、模型 Token 与柜月算力发现、评估、交易、置换和容量管理平台。

## 4. 标准业务说明

CloudPay 是企业算力撮合与交易管理平台。企业采购方可按照产品、厂商、地区、服务时段和交付条件，发现 GPU、模型 Token 与柜月资源，提交固定价订单或询价需求，并查看支付、交付、计量、验收、退款和对账状态。

企业供应商完成企业认证、资源归属核验和标准化测试后，可以将 GPU、Token 服务或柜月容量存入容量账本，设置服务区域、可售时间、SLA、数量和报价，并管理容量预留、订单交付与结算记录。

跨品类置换按照同一时点的人民币标准化参考价值计算建议数量和补差。参考行情只用于算力服务比较，不构成证券、期货、虚拟货币或投资产品。实际成交、交付和结算以订单、合同、验真容量、计量记录和支付机构结果为准。

首阶段仅面向企业用户。CloudPay 提供主体核验、资源验真、容量账本、订单撮合、交付记录和争议处理；具体算力服务由订单所示企业供应商交付。
