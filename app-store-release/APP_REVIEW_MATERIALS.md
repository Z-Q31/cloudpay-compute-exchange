# KAI Cloud 应用商店审核材料

版本：1.0  
更新时间：2026-08-11

> 本文件已经生成审核账号结构、登录方式、审核路径、演示数据和不真实扣款说明。实际账号、临时密码和后台数据必须在提交审核前由服务端真实创建。

## 1. 审核账号结构

| 角色 | 建议账号格式 | 主要权限 | 当前状态 |
| --- | --- | --- | --- |
| 企业采购方 | `review-buyer@[正式域名]` | 市场、报价、订单、容量、退款与注销 | 待创建 |
| 已认证供应商 | `review-supplier@[正式域名]` | 工作台、验真批次、上架、交付和结算 | 待创建 |
| 运营管理员 | `review-ops@[正式域名]` | 审核供应商、资源、退款、争议和结算 | 待创建 |

审核账号要求：

- 三个账号相互独立并采用最小权限；
- 使用短期临时密码，审核结束后轮换或禁用；
- 不在 App、截图、公开仓库或商店文案中写入密码；
- 审核账号只访问脱敏数据，不得展示真实设备 UUID、机房详细地址、银行账户和供应商底价；
- 如需要跳过短信验证码，只能使用服务端审核白名单和明确时间窗，不得形成通用后门。

## 2. 登录方式说明

1. 打开 KAI Cloud；
2. 在登录页输入审核账号和临时密码；
3. 若商店审核环境无法接收短信，使用审核白名单账号直接完成第二步验证；
4. 登录成功后按照角色进入对应首页；
5. 所有审核账号均可在“账户与合规”查看协议、隐私政策和账户注销入口。

正式提交时填写：

- 审核环境地址：`[待提供]`
- 采购方账号：`[待创建]`
- 采购方临时密码：`[待创建]`
- 供应商账号：`[待创建]`
- 供应商临时密码：`[待创建]`
- 运营账号：`[待创建]`
- 运营临时密码：`[待创建]`

## 3. 采购方审核路径

1. 登录企业采购方审核账号；
2. 进入“算力市场”；
3. 切换 GPU、Token、柜月和地区筛选；
4. 打开 H100 产品，查看配置、可售容量和订单快照；
5. 查看预置订单的支付、交付、计量与验收状态；
6. 进入“容量与存取”查看资产和取出申请；
7. 进入“账户与合规”查看隐私同意和注销入口。

## 4. 供应商审核路径

1. 登录已认证供应商审核账号；
2. 进入“供应商工作台”；
3. 查看企业认证状态、已验真批次和可售容量；
4. 进入挂牌管理查看报价、预留和订单；
5. 查看交付任务、计量和结算记录；
6. 查看资源取出条件和历史批次记录。

## 5. 运营审核路径

1. 登录运营管理员审核账号；
2. 查看供应商企业认证申请；
3. 查看资源验真材料摘要和容量批次；
4. 查看退款、争议、发票和结算状态；
5. 查看审计记录和人工操作原因。

## 6. 审核演示数据设计

以下是提交前应在服务端预置的脱敏数据结构，不代表真实交易：

| 演示数据 | 建议标识 | 展示状态 |
| --- | --- | --- |
| GPU 产品 | `KAI-DEMO-GPU-H100-001` | 9 张 H100、可售时间、地区和卡时单位 |
| Token 产品 | `KAI-DEMO-TOKEN-001` | 固定模型、服务商、上下文档位和有效期 |
| 柜月产品 | `KAI-DEMO-RACK-001` | 区域、功率、网络和服务期 |
| 已支付订单 | `KAI-REVIEW-ORDER-001` | 已支付、待交付 |
| 交付中订单 | `KAI-REVIEW-ORDER-002` | 已锁定、交付中 |
| 已验收订单 | `KAI-REVIEW-ORDER-003` | 已计量、已验收、待结算 |
| 退款订单 | `KAI-REVIEW-ORDER-004` | 退款审核中或已退款 |

演示数据必须：

- 明确标注为审核演示数据；
- 不包含真实企业、个人、银行、设备或机房敏感信息；
- 不计入真实收入、库存或结算；
- 审核结束后能够停用或清理，但保留必要审核日志。

## 7. 不发生真实扣款说明

审核账号无需完成真实扣款。审核环境通过预置的脱敏订单展示“待支付、已支付、交付中、已验收、退款中、已退款”等完整状态。

客户端支付完成页面不会直接改变订单最终状态。演示订单的支付状态由审核环境预置事件生成，不调用生产支付密钥，不产生真实资金流、发票或供应商结算。

## 8. App Review 审核备注

KAI Cloud 是面向企业的算力服务撮合与容量管理 App，不提供证券、期货、虚拟货币或可自由转让的金融合约。GPU、模型 Token 和柜月均为具体服务订单的交付单位；人民币价值快照仅用于服务比较和置换补差。

本次审核提供企业采购方、已认证供应商和运营管理员三个独立审核账号。审核数据均已脱敏，不包含真实供应商底价、设备 UUID、机房详细地址、银行账户或经办人信息。

审核人员无需发生真实扣款。系统已预置可查看支付、交付、计量、验收、退款和结算状态的审核订单。
