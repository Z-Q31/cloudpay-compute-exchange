## 2. 一句话定位

面向企业采购方与企业供应商的 GPU、模型 Token 和柜月算力发现、评估、交易、置换与容量管理平台。

## 3. 业务说明

KAI Cloud 是企业算力撮合与交易管理平台。企业采购方可以按照产品、厂商、地区、服务时段和交付条件发现 GPU、模型 Token 容量/用量及柜月资源，提交固定价订单或询价需求，并查看支付、交付、计量、验收、退款和对账状态。

企业供应商通过企业认证、资源归属核验和标准化测试后，可将 GPU、Token 服务或柜月容量存入容量账本，设置有效期、服务区域、SLA 和报价，再进行上架、预留、交付与结算管理。

跨品类置换按照同一时点的人民币标准化参考价值计算建议数量和补差。参考行情仅用于算力服务比较，不构成证券、期货、虚拟货币或投资产品。实际成交、交付和结算以订单、合同、验真容量、计量及持牌支付机构结果为准。

平台首阶段仅面向企业用户。KAI Cloud 负责身份核验、资源验真、容量账本、订单撮合、交付记录和争议处理；具体算力服务由订单所示企业供应商交付。

## 4. 商店文案

### Apple 宣传文本

### Google Play 短描述（80 字以内）

企业 GPU、模型 Token 与柜月资源的发现、采购、置换、存取和交付管理平台。

### 完整描述

KAI算力云为企业采购方和企业供应商提供统一的算力交易与容量管理入口。

主要功能：

• 算力市场：按产品、厂商、地区、时段、价格和交付条件筛选 GPU、Token 与柜月资源。  
• H100 采购：查看可售容量，配置服务时长和运行环境，跟踪预留、支付、交付与验收。  
• 智能报价：区分市场参考价、供应商要价和订单执行价，按地区及时间窗口展示。  
• 供应商工作台：企业认证、资源验真、容量存入、挂牌、订单交付和结算查询。  
• 供应商评估：按规格、地区、SLA、时间和服务条件形成可复核的人民币评估。  
• 算力置换：GPU、Token 与柜月按照同一时点的标准化人民币价值比较和置换。  
• 容量账本：查询已验真存入、报价预留、订单锁定、交付中、已消耗和风控冻结。  
• 订单与合规：记录支付、计量、验收、退款、争议、发票和结算流程。

KAI Cloud 展示的行情是同口径算力服务参考信息，不代表外部交易所价格，也不构成投资建议。订单执行价及服务内容以双方确认的订单与合同为准。

部分功能仅对完成企业认证的采购方、供应商或运营人员开放。支付能力需在支付宝、微信支付或其他持牌支付机构通道正式开通后使用。

## 6. 审核账号设计

实际账号须在提交审核前由服务端预置，不得把密码写入 App 或公开仓库。

| 角色 | 建议账号 | 审核权限 | 待提供 |
| --- | --- | --- | --- |
| 企业采购方 | `review-buyer@[正式域名]` | 市场、报价、订单、资产、退款与注销 | 实际账号和临时密码 |
| 已认证供应商 | `review-supplier@[正式域名]` | 工作台、验真批次、上架、交付和结算 | 实际账号和临时密码 |
| 运营管理员 | `review-ops@[正式域名]` | 审核供应商、资源、退款、争议和结算 | 实际账号和临时密码 |

审核安全规则：

- 每个账号独立、最小权限、可审计；
- 使用一次性或短期审核密码，审核完成立即轮换或禁用；
- 审核环境提供脱敏演示数据，不包含真实个人、机房、设备 UUID 或银行资料；
- 不允许审核人员发生不可逆真实扣款；使用支付机构沙箱、审核白名单或预置的已支付脱敏订单；
- 审核账号跳过短信验证码时必须仅限明确账号、审核时间窗和服务端策略，不得形成通用后门。

## 7. 审核路径

### 采购方路径

1. 登录采购方审核账号；
2. 进入“算力市场”，切换 GPU、Token、柜月和地区筛选；
3. 打开 H100 产品，查看配置、容量和订单快照；
4. 查看预置订单的支付、交付、计量与验收状态；
5. 进入“容量与存取”查看资产、申请取出；
6. 进入“账户与合规”查看隐私同意和注销入口。

### 供应商路径

1. 登录已认证供应商账号；
2. 进入“供应商工作台”；
3. 查看企业认证、已验真批次和可售容量公式；
4. 打开挂牌管理，查看报价、预留和订单；
5. 查看交付任务、计量和结算记录。

### 运营路径

1. 登录运营审核账号；
2. 查看供应商申请和资源验真材料摘要；
3. 查看退款、争议、发票和结算状态；
4. 查看审计记录与 App 发布自检。

## 8. 审核备注草案

KAI Cloud 是面向企业的算力服务撮合与容量管理 App，不提供证券、期货、虚拟货币或可自由转让的金融合约。GPU、模型 Token 和柜月均为具体服务订单的交付单位；人民币价值快照只用于服务比较与置换补差。

审核账号、登录步骤和各角色路径见本次提交的 App Review Information。审核数据已脱敏，不包含真实供应商底价、设备 UUID、机房详细地址或银行资料。

支付完成页不会直接修改订单状态；订单最终支付状态只接受持牌支付机构服务端签名通知。审核期间不要求审核人员完成真实扣款，已提供可查看完整状态链路的脱敏订单。

本 App 允许创建账户，并在“账户与合规 → 账户注销”提供 App 内注销入口；同时提供公开网页注销入口 `[HTTPS 注销页面 URL]`。
