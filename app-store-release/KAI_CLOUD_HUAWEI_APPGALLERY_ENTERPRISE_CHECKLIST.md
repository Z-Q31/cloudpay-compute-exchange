# KAI Cloud 企业主体上架华为应用市场材料清单

更新时间：2026-08-12  
适用范围：中国大陆企业主体；KAI Cloud（企业 GPU、模型 Token、柜月资源撮合与交易管理 App）；华为应用市场 AppGallery 公开上架。

> 使用说明：`[必交]` 是创建企业开发者账号、办理 APP 备案或提交应用时通常必须具备的材料；`[条件]` 仅在对应业务、支付方式或内容类型实际存在时准备；`[建议]` 不一定在控制台固定上传，但很可能影响审核或后续真实经营。华为控制台会根据应用分类、功能和发布地区动态显示最终材料，以提交当天页面要求为准。

## 一、先确定的上架信息

- [ ] **[必交] App 中文名：**建议确认为“`KAI 算力云`”或公司最终决定的正式名称
- [ ] **[必交] App 英文名：**建议确认为“`KAI Cloud`”
- [ ] **[必交] 运营主体：**填写营业执照上的公司法定全称
- [ ] **[必交] 发布类型：**确认本次提交 Android 应用，还是另行开发 HarmonyOS 原生应用
- [ ] **[必交] Android 包名：**建议最终确认为 `com.kaicloud.marketplace`，正式签名和创建华为应用记录后不要再修改
- [ ] **[必交] 首发版本：**建议 `1.0.0`，版本号与安装包内保持一致
- [ ] **[必交] 发布地区：**中国大陆；如同时发布境外地区，应另做跨境数据、语言、税务和当地资质评估
- [ ] **[必交] 商店分类：**按控制台当前分类选择最接近“商务/效率/企业服务”的分类，不将本应用申报为金融、证券、虚拟货币或游戏应用
- [ ] **[必交] 付费属性：**App 本身免费；App 内存在企业算力服务下单与支付，应在审核备注中如实说明

## 二、企业开发者账号实名认证材料

华为官方流程要求先注册开发者账号并完成实名认证，再进入 AppGallery Connect 创建和发布应用。

- [ ] **[必交] 公司专用华为账号**
  - 使用公司长期控制的手机号和邮箱注册
  - 不使用离职风险较高的个人邮箱作为唯一管理员
  - 开启双重验证并保存账号恢复信息
- [ ] **[必交] 营业执照或其他法律实体证件**
  - 在有效期内、完整、清晰、无遮挡
  - 公司名称、统一社会信用代码、注册地址和法定代表人可识别
- [ ] **[必交] 企业基本信息**
  - 公司法定全称
  - 统一社会信用代码
  - 注册地址和实际联系地址
  - 经营范围
- [ ] **[必交] 法定代表人材料**
  - 姓名、身份证号
  - 有效身份证正反面照片
  - 选择人脸认证时配合法人人脸核验
- [ ] **[必交] 开发者联系人/经办人材料**
  - 姓名、身份证号、手机号、邮箱
  - 经办人身份证件照片或人脸核验材料，以认证页面实际提示为准
  - 经办人不是法定代表人时，准备加盖公章的授权委托书
- [ ] **[条件] 对公打款认证材料**
  - 公司对公账户名称、账号和开户行
  - 华为要求的小额打款回执或账户支付凭证
- [ ] **[建议] 团队账号和权限表**
  - 企业主账号/超级管理员
  - 应用管理员
  - 开发人员
  - 运营及审核联系人
  - 财务/结算人员

> 华为公开的开发者隐私声明显示，企业开发者认证会处理法律实体证件、法人基本信息和身份证材料、联系人身份与联系方式；选择对公打款认证时还会处理银行账号和支付凭证。

## 三、公司品牌、版权和授权材料

- [ ] **[必交] 手机应用版权证明或代理证明**
  - 优先准备《计算机软件著作权登记证书》作为 KAI Cloud 的版权证明
  - 中国大陆发布的手机应用，华为当前规则中“应用版权证书或代理证书”为必选上传项
  - 证书上的软件名称、简称、版本号应尽量与提交应用一致
- [ ] **[条件] 版权授权链**
  - 上架企业、软件著作权人、开发商三者不一致时，提供完整授权书/委托开发合同/权利转让证明
  - 授权书应写明应用名称、包名、授权范围、发布平台、地区和期限并盖章
- [ ] **[条件] 商标或品牌授权**
  - “KAI”“KAI Cloud”“KAI 算力云”的商标注册证、申请受理通知书或合法授权
  - Logo 所有权或授权证明
- [ ] **[条件] 第三方素材授权**
  - 字体、图片、插画、图标、行情数据、模型厂商 Logo 等商业使用授权
  - 未获得授权时不要在商店素材或 App 中暗示与 NVIDIA、华为、阿里、腾讯、OpenAI 等厂商存在官方合作
- [ ] **[建议] 版权声明**
  - 格式：`© 2026 [营业执照公司法定全称]. All rights reserved.`

华为当前版权材料格式要求：

- 电子版权证书：可选，PDF，不超过 5MB
- 应用版权证书或代理证书：中国大陆手机应用必选；JPG/PNG/BMP，最多 10 张，每张不超过 15MB
- 授权书及其他材料：ZIP，不超过 200MB；仅放 JPG/JPEG/BMP/PDF；文件夹最多 3 层，累计不超过 200 张图片

## 四、APP 备案及互联网基础材料

在中国大陆提供互联网信息服务的 App 应先完成 APP 备案。华为上架指引也明确要求履行 APP 备案手续。

- [ ] **[必交] APP 备案主体材料**
  - 营业执照/统一社会信用代码证件
  - 主体负责人姓名、身份证件、手机号、应急电话和邮箱
  - APP 负责人姓名、身份证件、手机号、应急电话和邮箱
  - 真实性核验、承诺书及接入服务商要求的核验材料
- [ ] **[必交] APP 信息**
  - App 名称与图标
  - Android 包名或应用 ID
  - 签名证书公钥和 MD5 等签名信息
  - 运行平台、版本及服务内容说明
  - 实际使用的 SDK 厂商和功能类型
- [ ] **[必交] 网络与服务器信息**
  - App 使用的全部域名清单
  - 域名实名证明；所有者应与备案主体一致或具备合法授权
  - 服务器公网 IP、接入服务商、云服务商、服务器所在地
  - HTTPS 证书和域名解析信息
  - 已有网站 ICP 备案号及备案截图；已有网站备案时，按 APP 备案流程补充 APP 信息
- [ ] **[必交] APP 备案号**
  - 取得备案号后，在 App 的“关于/设置/底部信息”显著展示
  - 按备案要求链接至备案查询系统
  - 华为后台填写的名称、包名、公钥、MD5、域名必须与备案信息和正式安装包一致
- [ ] **[条件] 前置审批文件**
  - 如实际涉及互联网新闻、出版、教育、宗教、药品医疗、广播影视、互联网金融等前置审批领域，提供相应主管部门许可

## 五、KAI Cloud 业务相关条件资质

以下不等于“注册华为企业账号必交”，但 KAI Cloud 是第三方供应商和采购方之间的算力撮合及交易平台，提交前必须依据最终合同流、资金流、信息流和交付模式判断。

- [ ] **[建议/高优先级] 增值电信业务合规意见**
  - 由通信业务律师或公司所在地通信管理局确认是否需要：
    - `B21 在线数据处理与交易处理业务（EDI）`：平台为多方用户提供在线交易/事务处理时可能适用
    - `B25 信息服务业务（仅限互联网信息服务，俗称 ICP 许可证）`：有偿经营互联网信息服务时可能适用
    - `B11 互联网数据中心业务（IDC）`：若 KAI Cloud 自己经营 IDC/互联网资源协作服务，而不只是撮合，可能适用
  - 取得书面咨询结论、工单回复或法律意见并归档
- [ ] **[条件] 对应增值电信业务经营许可证**
  - 经评估需要 EDI、ICP 或 IDC 时，在正式经营相应业务前取得许可证
  - 若具体算力由供应商交付，归档供应商相应许可、云资源授权和资源归属证明
- [ ] **[必交/审核说明] 非金融、非虚拟货币说明**
  - 明确 `Token` 仅指具体模型、服务商、上下文档位、区域和有效期下的模型调用计量单位
  - GPU 卡时、Token 用量/容量时、柜月是具体可交付计算服务，不是证券、期货、虚拟货币或投资产品
  - K 线仅展示标准化算力服务历史报价/成交统计，不提供投资收益宣传
  - 置换以人民币标准化服务价值计算补差，最终交付具体算力服务
- [ ] **[必交/审核说明] 平台角色说明**
  - KAI Cloud 是企业算力撮合与交易管理平台
  - 标明合同签约主体、销售主体、开票主体、收款主体和实际服务交付主体
  - 标明供应商审核、资源验真、卡时核定、订单预留、支付、交付、验收、退款和争议路径
- [ ] **[建议] 供应商和资源证明样本**
  - 企业供应商营业执照、授权经办人、对公账户、开票资料
  - GPU 采购/租赁/托管/云账号证明及脱敏 UUID、规格、测试报告
  - 模型 Token 服务商授权、配额和计价档位证明
  - 柜月机房/机位/功率/网络和服务能力证明
  - 示例 H100 商品对应 9 张卡的合法来源、可售时段、验真和交付证明
- [ ] **[条件] 算力资讯内容资质**
  - 普通产品公告、行业知识和平台资讯应有来源、版权和后台审核记录
  - 若实际提供互联网新闻信息服务，应先取得相应许可；未取得前不要运营时政新闻采编、转载聚合业务
- [ ] **[条件] AI/算法合规材料**
  - 仅将 AI 用作内部卡时辅助核算且由人工终审时，在审核说明中如实描述
  - 如向公众提供生成式 AI、深度合成或具有舆论属性/社会动员能力的算法推荐，再办理适用的备案、登记、安全评估和显著标识
- [ ] **[条件] 网络安全等级保护材料**
  - 根据系统定级结论准备定级报告、备案证明、测评报告和整改记录
  - 此项未必是华为首次提交固定上传件，但涉及企业账户、交易和资源交付的生产系统应在上线前完成合规评估

## 六、支付宝、微信支付及华为支付规则确认材料

- [ ] **[必交] 支付模式说明**
  - 商品是企业云计算/算力服务，不是充值代币、可转让余额、虚拟货币或金融产品
  - 用户支付后获得订单约定的 GPU、Token、模型实例或柜月服务
  - App 前端支付成功页不直接改变订单最终状态；以支付机构服务端签名通知为准
- [ ] **[条件] 支付宝商户材料**
  - 企业支付宝商户号、签约产品、签约主体和审核通过页面
  - 应用 AppID、应用公钥/支付宝公钥或证书模式材料
  - 已备案支付域名、服务端异步通知地址和退款能力说明
  - 商户协议、费率、结算账户和客服信息
- [ ] **[条件] 微信支付商户材料**
  - 微信支付商户号、AppID 与商户号绑定关系
  - APIv3 密钥、商户证书序列号、平台证书、公钥 ID 等由服务端安全保管
  - 已备案支付域名、服务端回调地址和退款能力说明
  - 商户协议、费率、结算账户和客服信息
- [ ] **[必交/提交前确认] 华为应用内支付政策书面确认**
  - KAI Cloud 的 GPU/Token/柜月属于在线交付服务，容易被审核视为数字服务
  - 在正式提交前向华为开发者支持提交完整商品、合同、发票、支付和交付流程，取得“能否使用支付宝/微信支付，还是必须接入华为数字商品服务”的书面答复
  - 若被认定为华为数字商品，开通华为商户服务并签署《华为数字商品及联运服务协议》，使用沙盒账户完成测试
  - 未取得明确答复前，不要通过外部网页、二维码或引导文案规避应用市场支付规则
- [ ] **[建议] 资金合规说明**
  - 平台不收集银行卡密码、支付密码，不在客户端保存支付密钥
  - 平台不自行开展无牌支付、清算或资金池业务
  - 退款、撤销、拒付、分账和开票责任写入交易协议
