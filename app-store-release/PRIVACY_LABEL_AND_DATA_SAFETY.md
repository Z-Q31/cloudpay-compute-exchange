## 2. Google Play Data safety 底稿

### 数据收集与共享

- 是否收集用户数据：`是`
- 是否共享用户数据：`根据支付、短信、云服务和 SDK 的实际数据流填写`
- 数据是否传输加密：`应为是，提交前验证正式接口全部使用 HTTPS/TLS`
- 是否支持请求删除数据：`是，通过 App 内账户注销和公开注销说明`

### 数据类型与用途

| Google 数据类型 | 用途建议 | 必需或可选 |
| --- | --- | --- |
| 姓名 | 账户管理、企业认证 | 企业用户必需 |
| 邮箱地址 | 账户管理、通知、客服 | 按实际注册流程 |
| 手机号 | 账户管理、安全验证、通知 | 按实际注册流程 |
| 用户 ID | 账户管理、安全和审计 | 必需 |
| 地址 | 企业认证、合同或开票 | 仅相关企业用户 |
| 购买记录 | 订单、退款、交付和对账 | 交易用户必需 |
| 文件和文档 | 企业认证、资源证明 | 供应商必需 |
| App 互动 | 安全审计、故障排查 | 按实际日志 |
| 崩溃日志和诊断 | 稳定性与故障排查 | 按正式 SDK |
| 设备或其他标识符 | 会话安全、反欺诈 | 按实际实现 |
