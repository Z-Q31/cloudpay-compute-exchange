## 2. 开发目的

本软件面向企业采购方、企业算力供应商和平台运营人员，提供 GPU、模型 Token 与柜月资源的发现、评估、报价、容量管理、订单撮合、交付记录、计量对账和结算管理。软件通过标准化产品口径、容量账本和订单状态链路，降低异构算力服务的信息核对和履约管理成本。

## 3. 主要功能

1. 企业账户注册、登录和角色权限管理；
2. 企业供应商入驻、主体审核和资源归属材料管理；
3. GPU、Token 和柜月标准产品管理；
4. 算力市场筛选、固定价购买和询价；
5. H100 容量配置、订单预留和交付跟踪；
6. 市场参考价、供应商要价和订单执行价管理；
7. 多地区、多时段和多周期报价 K 线展示；
8. GPU、Token 和柜月人民币标准化价值评估与置换；
9. 容量存入、预留、锁定、交付、消耗、冻结和取出；
10. 支付状态、计量、验收、退款、争议、发票和结算记录；
11. 用户协议、隐私政策、账户注销和操作审计。

## 4. 用户角色

### 企业采购方

查询算力市场、提交固定价订单或询价、查看容量、支付、交付、计量、验收、退款和对账状态。

### 企业供应商

提交企业认证和资源证明，管理资源验真、容量存取、挂牌报价、订单交付、计量和结算。

### 平台运营人员

审核企业与资源，管理标准产品、报价、订单、退款、争议、结算和审计记录。

## 5. 软件特点

- 统一管理 GPU、模型 Token 与柜月三类异构算力服务；
- 使用容量账本记录已验真、预留、锁定、交付、消耗和冻结状态；
- 按产品、厂商、区域和时间窗口形成标准化报价；
- 使用人民币价值快照进行跨品类比较和建议补差；
- 区分公开行情、供应商内部要价和订单最终执行价；
- 通过角色权限和脱敏投影隔离供应商敏感资料。
