## 一、协议范围

本协议适用于用户访问或使用 KAI Cloud 网站、App、企业工作台及相关接口服务。KAI Cloud 面向企业采购方和企业供应商提供算力资源发现、评估、报价、撮合、容量管理、订单、交付记录、计量对账、退款、争议和结算管理。

## 二、账户与企业认证

1. 首阶段仅开放企业用户。申请人应具有代表企业操作账户、提交资料、创建订单或管理资源的合法授权。
2. 用户应提交真实、完整、有效的企业和经办人信息，并在信息变化时及时更新。
3. 用户应妥善保管账户、密码和验证码，不得转让、出租或允许无权人员操作。
4. 平台可以基于安全、合规或交易风险要求补充验证、限制部分功能或暂停账户。

## 三、平台角色

1. KAI Cloud 为算力服务撮合与交易管理平台，具体服务提供方以订单所示企业供应商为准。
2. 平台提供标准产品口径、资源验真、容量账本、订单流程、计量记录、争议处理和结算管理，但不对未经验证或超出订单范围的承诺负责。
3. 行情、指数、评估值和建议置换数量仅为同口径服务比较信息，不构成投资、证券、期货、虚拟货币或收益保证。

## 四、资源与报价

1. 供应商应确保资源来源合法、权属或使用权清晰，并如实说明规格、地区、时段、容量、SLA、限制和有效期。
2. 市场参考价、供应商要价和订单执行价相互区分。供应商底价和内部风控信息不公开。
3. 订单执行价以双方确认的订单快照、合同及服务端记录为准。

## 五、订单、支付与发票

1. 买方确认订单后，平台可在支付时限内预留容量；超时未支付时预留自动释放。
2. 支付结果以银行或持牌支付机构的服务端签名通知为准，客户端返回页不改变订单最终状态。
3. 支付、退款、分账、结算和发票按照订单、合同、支付机构规则及税务要求处理。
4. 发生错付、重复支付、拒付或异常交易时，平台可暂停交付并进行核查。

## 六、交付、计量与验收

1. 不同资源适用不同交付和计量标准，具体以产品页、订单和合同为准。
2. GPU 可记录可用卡数、运行时长、显存/错误和作业结果；Token 可记录模型、输入/缓存/输出用量、错误率和延迟；柜月可记录机位、功率、网络、开通时间和可用性。
3. 供应商侧与 KAI 侧计量差异超过阈值时，自动结算暂停并进入复核。
4. 买方应在验收期内确认或提出异议；逾期规则以订单和合同显著提示内容为准。

## 七、容量存取与置换

1. 可售容量按照已验真存入扣除报价预留、订单锁定、交付中、已消耗和风控冻结后计算。
2. 取出申请可能被立即处理、部分处理或排期处理；历史订单、计量、支付和结算记录不会因取出而删除。
3. GPU、Token 和柜月置换使用同一时点的人民币标准化价值快照比较；双方确认并锁定后执行，失败时按规则回滚或进入争议处理。

## 八、退款、取消与争议

1. 用户可按照产品页、订单、合同和公开规则申请取消或退款。
2. 已交付、已使用、定制或预留资源的退款范围可能受到限制，相关限制应在下单前显著提示。
3. 发生质量、计量、交付或资金争议时，平台可冻结相关容量和结算，并要求双方提交证据。
4. 退款、赔付和分账回退以持牌支付机构实际结果及平台追加分录为准。

## 九、禁止行为

用户不得提交虚假资料、重复承诺资源、超卖、规避计量、攻击系统、窃取凭据、洗钱、欺诈、侵犯第三方权利、违反出口管制或将服务用于其他违法用途。

## 十、知识产权与数据

1. KAI Cloud 软件、界面、文档和平台规则的相关权利归其合法权利人所有。
2. 用户保留其依法拥有的数据和材料权利，并授权平台在履行认证、交易、交付、风控和法定义务所必需的范围内处理。
3. 用户不得上传无权使用的商标、代码、模型、数据或其他材料。

## 十一、服务变更与责任边界

平台可能因维护、安全、监管、支付机构或供应商原因调整服务。对于可预见的重要影响，平台将按照适用规则通知用户。法律不允许排除或限制的责任不受本条影响。

## 十二、账户注销
