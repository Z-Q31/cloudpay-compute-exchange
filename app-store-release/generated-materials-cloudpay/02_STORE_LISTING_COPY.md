# CloudPay 华为应用市场商店文案

## 一、应用名称

CloudPay

## 二、一句话简介

面向企业的算力资源撮合、采购、供应与容量管理平台。

## 三、短描述

CloudPay 为企业采购方和认证算力供应商提供 GPU、模型 Token、模型服务与柜月资源的标准化展示、询价撮合、容量管理、订单交付和对账服务。

## 四、完整介绍

CloudPay 是面向企业用户的算力资源交易撮合与容量管理平台。

企业采购方可以按 GPU 型号、地区、可售时间、交付形式、服务等级和价格口径查找资源，发起固定价购买或询价需求，并在订单中查看容量预留、交付、计量、验收与对账状态。

企业供应商完成主体认证和资源验真后，可上架 GPU 算力、具体模型 Token 服务、模型实例容量或柜月资源。平台通过材料核验、远程测试、连接器或云厂商只读接口采集必要信息，对 GPU 卡时数、可用容量、性能和交付条件进行审核。审核通过后资源才进入公开市场。

主要功能：

- 企业采购：浏览标准产品、查看市场参考价、发起购买或询价；
- 供应商工作台：企业入驻、资源存入、商品提交、容量与订单管理；
- 资源验真：AI 辅助审计与人工复核相结合，记录 KAI 标准卡时数和证据摘要；
- 容量账本：展示已验真、已预留、已锁定、交付中、已消耗和冻结容量；
- 交付说明：每个商品明确标注 API 调用、远程登录服务器、专属实例或现场机柜服务等交付形式；
- 订单履约：记录支付确认、资源锁定、开通交付、计量、验收和结算状态；
- 供应商评估：按资源规格、地区、时段、服务等级和验真结果形成评估参考；
- 推荐分享：生成平台分享链接，便于企业邀请和业务推荐。

CloudPay 不向个人用户提供储值钱包、充值余额、提现或资金归集服务。具体交易、支付、发票和售后责任以订单、合同及平台公开规则为准。

## 五、版本更新说明

CloudPay 1.0.0 首次发布：

- 上线企业采购方与企业供应商注册登录；
- 上线供应商入驻、资源存入和商品审核流程；
- 支持 GPU、模型 Token 与柜月资源展示及询价撮合；
- 展示商品交付形式、可售容量、时间窗口、地区和服务等级；
- 上线容量账本、订单状态、计量验收和管理审核功能；
- 提供账号注销、隐私设置和客服反馈入口。

本应用主要服务企业用户。涉及交易的功能用于企业算力服务的展示、询价、订单和履约管理，不提供虚拟币、代币发行、证券期货、资金理财或个人储值钱包功能。
