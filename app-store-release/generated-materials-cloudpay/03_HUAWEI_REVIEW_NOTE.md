# CloudPay 华为应用审核说明

## 一、应用基本情况

- 应用名称：CloudPay
- 包名：`com.kaicloud.marketplace`
- 版本：1.0.0
- 开发者：上海申比芯人工智能科技有限公司
- 应用定位：企业级算力交易撮合与容量管理平台
- 目标用户：企业采购方、已认证企业供应商、平台管理员和后台工作人员

## 二、核心业务说明

CloudPay 展示和撮合 GPU 算力、具体模型 Token 服务、模型实例容量及柜月等现实企业服务。平台不是虚拟币、证券、期货、理财或个人转账产品，不提供面向用户的储值钱包、充值余额和提现功能。

供应商商品不会提交后立即公开。其企业主体及资源证明先进入审核，GPU 商品还需完成 AI 辅助审计和/或人工审计，核定 KAI 标准卡时数、可售时段和交付条件。审核通过后，管理人员才能批准上架。

每个商品页均明确展示一种或多种交付形式，例如：

- API 调用：通过短时访问凭据访问指定接口；
- 远程登录服务器：通过一次性领取链接获取短期登录凭据；
- 专属实例：交付指定模型实例或 GPU 环境；
- 现场/远程机柜服务：按合同交付机位、功率、网络和运维服务。

## 三、主要审核路径

### 1. 企业采购方

登录 → 算力市场 → 筛选 GPU/Token/柜月 → 商品详情 → 查看地区、时段、交付形式和价格 → 创建订单/发起询价 → 订单中心 → 查看交付和验收。

### 2. 企业供应商

登录 → 供应商工作台 → 企业认证 → 资源存入 → 新建商品 → 填写规格、容量、地区、时间窗口、报价和交付形式 → 提交审核 → 查看 AI/人工审核结果 → 审核通过后上架。

### 3. 管理员/后台工作人员

登录 → 管理系统 → 账号管理 / 企业认证 / 商品审核 / 卡时数审核 / 算力资讯审核 → 查看材料和证据摘要 → 通过、驳回或要求补充。

### 4. 账号注销

我的 → 设置 → 账号与安全 → 注销账号 → 身份校验 → 风险提示 → 提交注销。存在未完成订单、争议、退款、冻结或法定留存义务时，页面会说明原因和处理方式。

|---|---|---|---|
| 企业采购方 | `【待创建】` | 通过安全字段提交 | 预置示例订单，不发生真实扣款 |

## 五、支付与测试说明

- 前端“支付完成”页面不直接改变订单最终支付状态；
- 正式状态只接受银行或持牌支付机构的服务端签名通知，或依据经核验的对公银行回单由受权工作人员确认；
- 平台核对订单号、银行/机构流水号、收款主体、金额、币种、状态和幂等事件；
- 审核账号中的支付流程必须明确标记为测试，不发生真实扣款；
- 若正式版本尚未接通真实支付，应隐藏或禁用正式付款按钮，不得将 Mock 支付描述为正式能力。

## 六、隐私与权限说明

应用在首次启动时展示隐私政策，并在用户同意后按具体功能申请权限。头像或资质上传只在用户主动选择图片时申请相册/相机权限；通知权限用于订单、审核和交付状态提醒；设备和安全信息仅用于登录安全、风控和故障诊断。完整情况见《数据、SDK 与权限清单》。

## 七、需随审核提交的附件

- 营业执照清晰扫描件；
- APP 备案信息和已备案域名；
- 软件著作权证书或受理/补充说明（以华为当期要求为准）；
- 隐私政策、用户协议和注销说明的公开链接；
- 测试账号及完整测试路径；
- 正式签名安装包；
- 如审核要求，提供 EDI 资质结论、交易模式说明和资金路径说明。
