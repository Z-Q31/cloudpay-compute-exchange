## 一、协议范围

CloudPay 是面向企业用户的算力资源交易撮合和容量管理平台。平台提供企业身份核验、资源信息展示、询价撮合、容量预留、订单管理、交付协助、计量验收、对账和争议处理等技术服务。

本协议适用于注册、登录、浏览和使用 CloudPay 的企业采购方、企业供应商经办人及其他获授权用户。供应商还须签署《供应商入驻与平台服务协议》，采购方在创建订单时还须确认订单、商品规则及具体服务合同。

## 二、账号注册与企业授权

1. 首阶段仅向依法设立的企业及其授权人员开放核心交易功能。
2. 用户应提供真实、准确、完整、有效的信息，并在变化时及时更新。
3. 经办人应确保已获得企业授权。企业对其账号下授权人员实施的操作承担相应责任，但能证明账号被盗用且已及时通知平台的除外。
4. 用户应妥善保管登录凭证、验证码和设备，不得向他人出借、出租或出售账号。
5. 平台可基于安全和合规需要进行企业主体、经办人、对公账户和操作权限核验。
6. 发现冒用、泄露或异常操作时，用户应立即通过客服渠道通知平台。

## 三、平台服务

平台可提供：

- 算力商品搜索、筛选、行情参考和报价展示；
- 固定价购买、RFQ 询价、未来时段预留和经审核的容量置换；
- 供应商入驻、资源存入、商品提交和审核；
- 容量账本、订单、支付状态、交付、计量、验收和对账记录；
- 供应商等级、脱敏区域、产品规格、SLA 和标准化价格展示；
- 推荐分享、通知、客服、投诉和争议协助；
- 法律法规允许且已在产品中明确的其他服务。

市场参考价、指数、AI 评估和建议补差仅供交易决策参考，不构成保本、收益或成交承诺。最终权利义务以订单执行价、合同和交付验收规则为准。

## 四、算力商品与价格口径

1. GPU 商品应指向具体型号、卡数/卡时、地区、时段、网络/存储条件、服务等级和交付形式。
2. Token 实际用量订单应指向“模型 + 服务商 + 上下文档位 + 价格类型 + 服务区域 + 有效期”，输入、缓存和输出 Token 可分别计价。
3. Token 容量时购买的是约定时段内保证的模型吞吐或限额，不等同于已经实际调用的百万 Token 用量。两者不得混为同一价格。
4. 柜月商品应指向地区、机位、功率、网络、期限、开通条件和服务等级。
5. 平台可展示市场参考价、供应商要价和订单执行价。供应商底价、原始报价和内部风控信息不公开给无关方。
6. 标准化有效单价可包含资源价、税费调整、电费、网络流量、必选存储、开通及最低消费摊销和可量化 SLA 风险调整。页面应披露计算口径。

## 五、订单与容量预留

1. 用户提交订单或确认询价方案后，平台可预留相应容量并设置支付期限。
2. 预留不等于最终交付。正式锁定以订单支付确认、供应商交付确认和平台规则为准。
3. 支付超时、容量失效、供应商不能交付或风控拦截时，订单可取消、重新匹配或进入人工处理。
4. 订单创建后固化商品规格、数量、地区、时间、交付形式、价格、税费、服务费、供应商、规则版本和推荐归因等快照。
5. 用户不得利用接口重放、并发下单或虚假交易占用容量。

## 六、支付、发票和退款

1. 第三方供应商订单原则上由采购方向订单列明的供应商对公账户支付，供应商向采购方开具算力服务发票；平台另行向供应商收取技术服务费并开具相应发票。
2. 平台自营商品由运营主体作为卖方收款、开票并履约，页面应标注“平台自营”。
3. 前端页面显示“已提交”或“支付完成”不代表最终支付成功。平台以银行或持牌支付机构服务端通知，或经复核的对公入账记录为准。
4. 退款、取消、赔付和拒付按订单、商品规则及《交易、退款与争议处理规则》执行。
5. 如后续接入持牌支付机构，用户还须遵守该机构规则。

## 七、交付、计量和验收

1. 商品页和订单应明确交付形式，包括 API、远程登录服务器、专属实例或柜月服务。
2. 交付凭据通过一次性领取、短时凭据或采购方公钥加密方式提供。用户不得向无关方泄露。
3. 计量可采用供应商连接器与平台网关/探针双源比对，记录资源、订单、起止时间、用量、性能、错误、采集方、签名和证据摘要。
4. GPU、Token、模型实例、NAS 和柜月按各自产品验收规则执行。
5. 用户应在约定期限内验收或提出异议。计量差异超过阈值时，平台可暂停自动结算并人工复核。

## 八、使用规范

用户不得：

- 违反法律法规或侵害他人合法权益；
- 上传虚假企业、资源、许可、报价、计量或交付材料；
- 重复存入、跨平台重复承诺已独占资源或超卖容量；
- 未经授权扫描、攻击、逆向、干扰平台或他人资源；
- 使用算力从事诈骗、网络攻击、违法内容生成、侵犯知识产权或其他违法活动；
- 规避计量、费用、审计、安全或访问控制；
- 公开设备 UUID、机房详细地址、云主账号密码、SSH 私钥、root 密码或他人敏感信息；
- 以平台名义作出未经授权的承诺。

## 九、账号限制、暂停与退出

发生信息不实、异常交易、安全风险、监管要求、司法冻结、重大投诉或违反协议时，平台可根据风险程度采取提醒、补充核验、限制功能、停止新订单、冻结容量、暂停账号或终止服务。紧急情况下可先处置后通知，并保留审计记录。

用户可按注销规则申请注销。注销不删除依法或为履行未完结合同、解决争议所必需保留的订单、支付、计量、发票、审计和安全记录。

## 十、知识产权

CloudPay 的软件、页面、商标、规则、标准、指数方法和文档由运营方或合法权利人享有。用户保留其合法上传内容的权利，并授权平台在提供服务、审核、展示、履约和合规所必需范围内处理相关内容。

## 十一、数据与隐私

平台按照《CloudPay 隐私政策》处理个人信息。企业经办人应确保向平台提供第三方个人信息时具有合法处理依据。采购方模型、数据和存储内容与公开投影分离，并按合同、权限和保留期限管理。

## 十二、服务变更与中断

因维护、网络、云服务、不可抗力、安全事件或监管要求，服务可能暂停或调整。平台将按影响程度提前通知或及时说明，并依据订单 SLA 和法律规定处理。平台不免除因故意或重大过失造成损失时依法应承担的责任。

## 十三、责任与赔偿

1. 供应商对资源真实性、合法来源、可交付性和交付质量负责。
2. 采购方对其使用方式、数据、作业和凭据安全负责。
3. 平台对自身提供的撮合、账本、审核和技术服务依法承担责任，但不对供应商作出的未经平台确认的承诺负责。
4. 任何责任限制不得排除或限制法律不得排除的责任，不得不合理减轻平台责任或加重用户责任。

## 十四、规则变更

平台规则遵循公开、公平、公正原则。涉及用户重大权益的变更将按法律要求公开征求意见、显著提示、设置合理过渡期并保留历史版本。用户不同意变更的，可在处理完未完成订单和义务后停止使用。

## 十五、适用法律与争议解决

本协议适用中华人民共和国法律。争议应先通过客服协商；协商不成，任何一方可向依法有管辖权的人民法院提起诉讼。该约定不影响消费者或其他主体依法享有的法定权利。
