# CloudPay 交易、取消、退款与争议处理规则（草案）

版本：V1.0  
发布主体：上海申比芯人工智能科技有限公司

## 一、价格体系

平台为算力购入和置换区分三层价格：

1. **市场参考价**：相同标准产品、地区、时间和口径的公开报价与成交统计；
2. **供应商要价**：供应商底价、目标价和有效期，其中底价及原始报价不公开；
3. **订单执行价**：双方通过固定价、询价或协商确认的最终价格。

标准化总成本可由资源价、税费调整、电费、网络与流量、必选存储、开通及最低消费摊销和可量化 SLA 风险调整组成。

标准化有效单价 = 标准化总成本 ÷ 可交付标准单位。

页面应说明时间粒度和地区。日内时段可按深谷、谷段、平段、峰段和尖峰等标签展示，但具体名称、起止时间和调价系数必须在商品中明确，不得仅显示“5分、15分”等无法理解的数字。K 线周期可提供 5 分钟、15 分钟、1 小时、日、周和 1 个月视图；行情不构成成交承诺。

## 二、固定价购买

适用于规格标准、库存新鲜且交付自动化程度高的资源。买方确认商品、数量、地区和时间后，平台原子预留容量并生成待支付订单。预留有效期在订单中展示。支付超时，预留自动释放，历史事件保留。

## 三、RFQ 询价

适用于大额 GPU 集群、柜月、复杂 NAS 和定制模型服务。需求方发布脱敏需求，匹配供应商分别提交原始报价，平台按统一口径标准化后向需求方展示。供应商之间不得互相查看原始报价、底价或身份敏感信息。

## 四、未来容量预留

需求方可以预订未来时间窗口。预留费、取消规则、可变数量、交付前复验、替代资源和 SLA 写入订单或合同。平台首阶段只提供现实服务预订，不设计可自由转让的远期、期货或证券化产品。

## 五、双边置换

GPU、Token 和柜月可以互相置换，但必须采用人民币价值比较，不发行平台代币。

1. 双方资源均完成验真并进入容量账本；
2. 平台按同一时点、地区、时段和服务档位的标准化参考价生成价值快照；
3. 快照展示原始单位、数量、价格来源、时间、标准化人民币价值和建议补差；
4. 双方复核确认后，平台原子锁定两边容量；
5. 补差款通过银行或持牌支付渠道支付；
6. 任一侧锁定、支付或交付失败时，按订单整体回滚或进入争议处理；
7. 双方最终收到订单约定的具体 GPU、Token、模型实例或机柜服务，人民币标准化价值只用于比较和补差，不替代实际交付、合同、计量、税务和结算。

Token 实际用量和 Token 容量时不得混为同一标的。Token 订单必须指向具体模型、服务商、上下文档位、输入/缓存/输出价格类型、服务区域和有效期。

## 六、完整订单状态

建议状态顺序：

草稿 → 待供应商确认 → 容量已预留 → 待支付 → 支付核验中 → 已支付/容量已锁定 → 待交付 → 交付中 → 待验收 → 已验收 → 待结算 → 已完成。

异常分支包括：已取消、支付失败、退款中、已退款、交付异常、复核中、争议中、风控冻结和已关闭。每次状态变化须有全局 `event_id`、幂等键、时间和操作来源。

## 七、支付确认

前端支付完成页面不改变订单最终状态。平台只接受银行或持牌支付机构的服务端签名通知，或经授权双人复核的对公入账证据，并核对：

- 平台订单号和银行/支付机构流水号；
- 付款方、收款方、商户、金额、币种和状态；
- 通知签名与证书有效性；
- 幂等键和已处理事件；
- 退款、撤销和拒付状态。

## 八、取消规则

| 阶段 | 原则 |
|---|---|
| 容量预留前 | 买方可取消，不产生资源占用费用 |
| 已预留、未支付 | 按商品公示规则释放；如有已明确预留费，按合同处理 |
| 已支付、未交付 | 根据供应商准备成本、取消原因和合同处理 |
| 已交付、未使用 | 是否可退取决于资源专属性、凭据是否激活及订单规则 |
| 已使用/已验收 | 已实际交付部分原则上不退；未交付部分和违约部分依法处理 |

任何不退款或扣费条款均应在购买前显著提示，并不得排除法律规定的权利。

## 九、退款流程

1. 采购方在订单中提交退款原因、数量和证据；
2. 系统冻结争议部分结算，不影响无争议部分；
3. 供应商在规定期限内回应；
4. 平台核对订单、容量、交付、计量、SLA、支付和沟通记录；
5. 达成一致后，由原收款主体按原路径或对公方式退款；
6. 平台记录退款流水、容量回补、服务费冲正和发票处理；
7. 无法协商时进入争议处理。

## 十、SLA 赔付

各商品须事先固定可用性、性能、延迟、错误率、响应和赔付口径。服务抵扣、补交付和现金退款的顺序与上限以订单为准，但不得免除故意、重大过失或法律不得限制的责任。

## 十一、争议证据

有效证据包括订单快照、合同、支付回调、银行回单、连接器和网关计量、签名日志、资源状态、交付凭据领取记录、作业结果、错误、沟通记录、发票、操作审计和原始证据摘要。任何一方不得篡改或删除争议证据。

## 十二、处理时限

- 平台确认收到投诉：建议 1 个工作日内；
- 供应商首次回应：建议 2 个工作日内；
- 普通争议初步结论：建议材料完整后 7 个工作日内；
- 复杂技术/计量争议：建议材料完整后 15 个工作日内；
- 需要司法、监管或第三方鉴定时，告知延期原因和进度。

正式时限由运营和法务确认后写入公开版本。

## 十三、规则版本

平台保留规则版本号、发布时间、生效时间、修改说明和历史文本。涉及重大权益的变更依法公开征求意见、显著提示并设置合理过渡期。
