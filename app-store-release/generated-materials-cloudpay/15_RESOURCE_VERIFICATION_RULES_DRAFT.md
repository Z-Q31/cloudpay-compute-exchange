# CloudPay 算力资源验真、卡时审计与复验规则（草案）

版本：V1.0

## 一、目标

确保上架资源真实、可控、未超卖、可按订单交付，并用可复核证据核定 KAI 标准卡时数、Token 服务能力或柜月交付能力。验真结论不等于永久有效，资源须接受持续监测和复验。

## 二、三种接入模式

| 模式 | 使用场景 | 能力 | 交易限制 |
|---|---|---|---|
| 人工材料 + 远程测试 | 首笔交易、小供应商 | 人工核对资源证明并运行测试任务 | 库存由运营确认，不能声称实时 |
| KAI 轻量连接器 | 自有 GPU、服务器、NAS | 上报规格、可用状态、任务和签名心跳 | 支持持续验真、自动锁定和释放 |
| 云厂商只读 API/子账号 | 云资源和模型配额 | 读取规格、配额、账单和运行状态 | 最小权限，不接收主账号密码 |

## 三、供应商主体先决条件

资源审核前，供应商应处于“审核中”或“已认证”状态，并完成企业主体、授权经办人、对公账户、开票资料、许可及资源归属证明核验。主体认证、许可或结算账户异常时停止资源上架。

## 四、GPU 存入检查

GPU 存入单至少经过：

1. 资源归属、托管合同或云账号证明核对；
2. GPU 型号、设备 UUID 不可逆摘要、显存、驱动、CUDA/运行环境和拓扑采集；
3. 标准基准任务和显存错误检查；
4. 网络、存储、温度、电力和其他交付条件检查；
5. 连续签名心跳观察；
6. 重复存入、跨平台重复承诺和异常占用检查；
7. 地区和可售时间窗口核验；
8. API、远程登录服务器或专属实例等交付形式验证；
9. 凭据发放、回收、日志和应急交付测试。

设备 UUID 原文只保存在受限证据库。公开页和一般工作人员只访问不可逆摘要或脱敏标识。

## 五、KAI 标准卡时数审计

### 1. 输入

- 实际 GPU 型号和数量；
- 可用显存、互联拓扑和算力测试；
- 可售起止时间和日内时段；
- 预计维护、现有任务和资源占用；
- 地区、网络、存储、温度和 SLA；
- 连接器心跳稳定性和证据可信度。

### 2. 计算原则

原始卡时 = 通过验真的可用卡数 × 可交付小时数。

KAI 标准卡时可在公开方法中按目标标准卡性能、可用性、互联、网络存储和风险系数进行折算，但必须同时保留原始卡时。计算公式、基准版本、样本时间和人工调整理由可追溯。

示意公式：

KAI 标准卡时 = 原始卡时 × 性能折算系数 × 可用性系数 × 交付条件系数 × 证据可信度系数。

正式系数由技术委员会批准并公开方法说明。未经审批不得用示意系数计费。

### 3. AI 审计

AI 可用于材料一致性检查、异常检测、重复资源识别、基准结果分析和建议折算，不得无人工监督直接批准高风险、异常或首笔资源。AI 输出须记录模型/规则版本、输入证据摘要、置信度和理由。

### 4. 人工审计

审核人员复核关键证据，可要求补测、视频见证、云只读核验或现场证明。人工更改 AI 建议必须记录理由。高价值集群、异常结果和关联交易采用双人复核。

## 六、Token 服务验真

Token 商品必须指定：

**模型 + 服务商 + 上下文档位 + 价格类型 + 服务区域 + 有效期**。

验真包括模型身份/版本、服务商授权或配额证明、上下文长度、输入/缓存/输出计量、速率限制、并发、吞吐、延迟、错误率、区域、有效期和 API 交付测试。

Token 容量时和百万 Token 实际用量建立不同产品、单位、价格和计量字段。模型综合指数只表示固定模型篮子的相对成本变化，不作为单一模型成交价。

## 七、柜月验真

柜月商品至少核验机房运营/托管权、脱敏区域、机位数量、单柜功率、计费电量、网络线路、带宽、IP、制冷、消防、物理安全、运维窗口、开通周期、服务期限、SLA、现场交付和退出条件。详细机房地址仅向履约所必需且有权限的采购方披露。

## 八、商品审核结论

- 通过：生成容量批次和审核报告，商品进入待上架；
- 补充材料：说明缺失项、期限和复测要求；
- 驳回：说明事实和规则依据，保留申诉入口；
- 限制通过：限定数量、时间、客户、交付形式或复验频率。

商品必须同时写清交付形式，缺少交付形式不得通过。

## 九、复验触发

- 到达定期复验日；
- 连接器失联、心跳漂移或性能下降；
- 型号、驱动、拓扑、地区、配额、账户或结算信息变化；
- 大额订单、长周期预留或交付前复验要求；
- 投诉、计量差异、超卖嫌疑、异常占用或安全事件；
- 资源证明或许可变化；
- 监管或平台规则要求。

复验期间可停止新订单、降低可售容量或冻结资源，但应尽量保障已成立订单并通知相关方。

## 十、审核记录

每份报告保留资源 ID、批次、证据摘要、测试命令/任务版本、原始结果哈希、AI/规则版本、审核人、时间、结论、有效期、限制和申诉记录。原始证据与公开投影分离。
