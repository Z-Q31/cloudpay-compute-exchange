# CloudPay 商品与算力资讯内容审核制度（草案）

版本：V1.0  
适用角色：平台管理员、后台工作人员、供应商审核人员、资讯编辑

## 一、审核对象

- 企业供应商注册与认证材料；
- GPU、Token、模型实例、NAS 和柜月商品；
- KAI 标准卡时数、容量、报价和交付形式；
- 供应商公开页；
- 平台发布或供应商提交的算力资讯、产品说明和活动信息；
- 图片、附件、外链、评论或其他公开内容（如上线）。

## 二、角色与权限

| 角色 | 权限 |
|---|---|
| 超级管理员 | 配置角色、规则版本和最终高风险审批；不得日常共用账号 |
| 管理员 | 查看和管理注册/登录账号、分配审核、处理申诉和冻结 |
| 后台工作人员 | 按分配任务审核企业、商品、卡时数和资讯；无权修改系统密钥或删除审计记录 |
| AI 审核服务 | 输出风险标签、相似/重复检测和建议，不独立完成高风险最终批准 |
| 复核人员 | 处理异常、大额、申诉和人工调整，原则上与初审分离 |

所有工作人员使用独立账号和最小权限，不得共用管理员密码。关键操作记录操作人、理由、前后状态和证据。

## 三、供应商账号审核

检查企业主体、授权经办人、对公账户、开票资料、许可和资源证明。状态为：待提交 → 审核中 → 已认证 → 受限 → 已暂停 → 已退出。至少每六个月复核，重大信息变化即时复核。

## 四、商品审核

商品审核必须确认：

- 资源已验真，容量批次有效；
- GPU 已完成 AI/人工卡时数审计；
- 产品类型、型号/模型、数量、地区和可售时间准确；
- 价格口径、税费、电费、网络、存储和最低消费清楚；
- 交付形式明确标注 API、远程登录服务器、专属实例或柜月现场/远程服务；
- SLA、取消、退款、验收和有效期清楚；
- 无虚假宣传、绝对化用语、保收益、误导性“实时库存”或无法证明的性能；
- 公开内容未泄露设备 UUID、机房详细地址、资源证明、底价、原始报价和内部风控备注；
- Token 实际用量和 Token 容量时未混价；
- 无违法、侵权、欺诈、虚拟币或未经许可的金融活动。

缺少交付形式、验真批次或价格口径的商品必须驳回或要求补充，不得直接上架。

## 五、算力资讯审核

平台“算力资讯”定位为企业自有产品说明、行业资料整理和技术知识，不开展互联网新闻信息采编发布服务。审核人员检查：

- 来源、作者、发布日期和授权；
- 标题与正文一致，无标题党或误导；
- 引用数据注明时间、地区、口径和来源；
- 不虚构政策、价格、厂商合作或资源库存；
- 不侵犯著作权、商标、商业秘密或个人信息；
- 不含违法、有害、歧视、色情、暴力、赌博、诈骗、恶意软件或攻击指导；
- 涉及医疗、金融、法律等专业内容时增加来源和风险提示；
- AI 辅助生成内容经人工事实核验，不把 AI 输出冒充权威结论。

## 六、审核结果

- 通过：记录审核人、版本和发布时间；
- 驳回：列明问题和规则依据；
- 补充材料：列明材料、格式和期限；
- 限制展示：仅对特定企业、地区或权限可见；
- 下架/冻结：发生证据失效、投诉、异常或风险时执行。

申请人可在 `【待定】` 个工作日内申诉。复核人员不得是同一事项的唯一初审人员。

## 七、资讯更正和下架

发现错误或权利人投诉时，先保存原版本和证据，再按风险更正、标注、限制或下架。不得直接覆盖历史而不留记录。重大更正向受影响用户通知。

## 八、敏感信息处理

原始证据和公开投影分离。审核界面按角色脱敏展示，下载和导出受控。禁止把营业执照、身份证、银行账户、设备标识、机房地址、客户模型/数据和内部备注转发到个人聊天或未授权工具。

## 九、审核质量

每月抽查通过与驳回样本，统计误审、申诉改判、响应时间和异常重复率。规则或模型调整建立版本、测试样本、批准人和回滚方案。
