# CloudPay 数据、SDK 与权限清单

版本：V1.0  
核对基线：CloudPay 1.0.0 / Expo SDK 54 / React Native 0.81.5

> 本清单根据当前项目依赖生成。正式提审前必须以最终 AAB/APK 的权限、SDK 扫描和真机网络行为为准；只要安装包变化，就重新核对。

## 一、个人信息字段清单

| 场景 | 数据类型 | 是否敏感 | 目的 | 触发方式 | 公开范围 |
|---|---|---|---|---|---|
| 注册登录 | 手机号、验证码、登录时间、账号角色 | 手机号可能属于个人信息 | 认证和账号安全 | 用户主动注册/登录 | 不公开 |
| 企业认证 | 经办人姓名、职务、企业邮箱、授权材料 | 视材料内容 | 企业授权核验 | 用户主动提交 | 不公开 |
| 主体核验 | 营业执照、企业名称、统一社会信用代码 | 企业信息；可能含代表人个人信息 | 供应商/采购方认证 | 用户主动提交 | 仅公开必要企业名称/等级 |
| 结算开票 | 对公账户、开票资料、银行流水摘要 | 账户信息敏感 | 对账、开票、付款核验 | 订单和企业认证 | 不公开 |
| 资源验真 | GPU UUID 摘要、规格、心跳、云只读资源信息 | 原始设备标识受限 | 证明资源和防超卖 | 连接器/授权接口 | 仅公开标准规格和脱敏地区 |
| 商品订单 | 商品、报价、订单、合同、容量、交付、计量 | 可能含商业秘密 | 履约与争议 | 交易过程 | 按角色显示 |
| 支付状态 | 订单号、银行/机构流水号、金额、币种、状态 | 财务信息敏感 | 支付确认和对账 | 服务端回调/财务复核 | 不公开 |
| 客服审核 | 联系方式、问题、附件、操作记录 | 取决于内容 | 审核和投诉处理 | 用户主动提交/工作人员操作 | 不公开 |
| 设备安全 | 设备/应用版本、IP、安全日志、崩溃信息 | 可能构成个人信息 | 风控和故障诊断 | 登录/使用期间 | 不公开 |

## 二、原生权限清单

| 权限/能力 | 当前用途 | 申请时机 | 拒绝后的影响 | 提审动作 |
|---|---|---|---|---|
| 网络访问 | 访问正式 API、图片和服务 | 使用联网功能时 | 无法登录和使用在线服务 | 必需；确保 HTTPS |
| 相册/图片选择 | 用户主动上传头像、营业执照或资源材料 | 点击“选择图片”后 | 可取消上传；其他功能不受影响 | 使用系统选择器，避免读取全部相册 |
| 相机（如最终包包含） | 拍摄资质或资源证明 | 点击“拍摄”后 | 可改用相册/文件上传 | 若未使用应从最终包移除 |
| 通知（如正式启用） | 订单、审核、交付和安全提醒 | 用户开启通知时 | 仅无法收到系统通知 | 单独说明，可在系统设置关闭 |
| 安全存储 | 保存短期会话令牌/本机安全配置 | 登录后 | 可能无法保持登录 | 不保存密码、私钥和支付密钥 |
| 本地数据库/文件 | 缓存非敏感页面和草稿 | 使用相应功能时 | 可能影响离线体验 | 注销和退出时按规则清理 |
| 浏览器/深链 | 打开协议、一次性凭据领取和回跳 | 用户主动点击 | 无法打开外部页面 | 仅允许 HTTPS/受信域名 |
| 触觉反馈 | 按钮操作反馈 | 用户操作时 | 无实质影响 | 可选 |

当前核心功能不需要通讯录、精确定位、后台定位、麦克风、通话记录或短信读取权限。若最终包出现上述权限，应先查明来源并移除，确有必要时再更新政策和交互。

## 四、尚未检测到的商业 SDK

当前依赖中未发现支付宝、微信支付、广告、商业统计、地图、社交分享、云厂商身份核验或商业崩溃分析 SDK。若后续接入，必须在上线前：

1. 记录 SDK 名称、版本、运营主体和官网隐私政策；
2. 记录收集数据、目的、方式、频率、权限和初始化时机；
3. 在用户同意隐私政策前禁止非必要初始化；
4. 对敏感信息和向第三方提供取得单独同意（适用时）；
5. 更新本清单、隐私政策、商店数据安全表和 APP 备案信息；
6. 使用最终包重新抓包和扫描。
