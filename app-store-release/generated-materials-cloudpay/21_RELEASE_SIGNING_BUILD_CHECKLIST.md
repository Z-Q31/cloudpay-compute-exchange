# CloudPay 正式签名、构建与发布检查清单

版本：1.0.0

## 一、身份冻结

- [ ] App 名称固定为 CloudPay
- [ ] Android 包名固定为 `com.kaicloud.marketplace`
- [ ] iOS Bundle ID 固定为 `com.kaicloud.marketplace`
- [ ] 开发者主体为上海申比芯人工智能科技有限公司
- [ ] versionName 为 1.0.0，versionCode 为 1
- [ ] 隐私政策、备案、软著和商店信息使用相同名称和主体

## 二、正式域名和后端

- [ ] 正式 API 使用已备案 HTTPS 域名
- [ ] 证书有效，完整证书链和 TLS 配置通过测试
- [ ] 移除 `api.example.invalid`、`127.0.0.1` 和本地端口
- [ ] 关闭 `EXPO_PUBLIC_USE_MOCKS=true`
- [ ] 登录、短信、企业认证、商品、审核、订单、支付状态、注销全部连接正式服务
- [ ] 服务器时间、数据库备份、监控、告警和审计可用
- [ ] 支付回调、防重放、验签和幂等经过测试

## 三、密钥和签名

- [ ] 使用公司控制的正式 Android 上传/发布密钥
- [ ] 密钥库、别名、口令不写入源码、聊天或公开仓库
- [ ] 至少两名授权人员可恢复密钥，恢复过程有审批和离线备份
- [ ] 提取并记录签名证书 SHA-256、有效期和主体
- [ ] 签名与 APP 备案、AGC 应用记录一致
- [ ] AAB 签名校验通过
- [ ] 生成 AAB SHA-256 并写入发布记录
- [ ] 详细操作参照 `../../gitee-pod/docs/HUAWEI_RELEASE_IDENTITY_AND_SIGNING.md`

## 四、功能闭环

- [ ] 企业采购方能注册、登录、找回/重置凭证和注销
- [ ] 企业供应商能入驻、提交材料、存入资源、提交商品、查看审核和取出
- [ ] 管理员能管理账号、企业、商品、卡时数和资讯审核
- [ ] 后台工作人员能用独立账号登录并按授权审核
- [ ] GPU 商品提交后必须经过 AI/人工卡时数审核才上架
- [ ] 每个商品显示 API、远程登录服务器、专属实例或柜月等交付形式
- [ ] H100 市场能显示真实可售数据，不只是静态入口
- [ ] 容量账本能显示已验真、预留、锁定、交付中、消耗和冻结
- [ ] 支付页面不直接改变最终订单状态
- [ ] 交付、计量、验收、退款、对账和争议均有状态和证据
- [ ] 推荐分享不会调用崩溃的系统能力，失败时有降级提示

## 五、隐私和安全

- [ ] 首次启动在收集非必要信息前展示隐私政策并取得同意
- [ ] 登录前和设置页可随时查看用户协议、隐私政策和注销说明
- [ ] 权限在用户触发功能时申请，拒绝后有可理解说明
- [ ] 最终 AAB 权限与 `18_DATA_SDK_PERMISSION_INVENTORY.md` 一致
- [ ] 最终 SDK 和网络请求与公开清单一致
- [ ] 不收集云主账号密码、SSH 私钥、root 密码或支付密钥
- [ ] 一次性凭据和短时凭据可到期、撤销和审计
- [ ] 个人信息和原始证据按角色脱敏
- [ ] 账号注销真正可用，不是仅展示页面

## 六、兼容与质量

- [ ] 路由自动检查全部通过
- [ ] 类型检查、代码检查、前端测试和后端测试通过
- [ ] 新装、升级、退出重登和清缓存场景通过
- [ ] 主流华为手机、不同分辨率和字体大小测试通过
- [ ] 手机端和平板/折叠屏基础布局无截断
- [ ] 深色/浅色模式文字对比度合格
- [ ] 弱网、断网、接口超时和服务器错误有提示与重试
- [ ] 无 404、路由不存在、白屏、崩溃和无限加载
- [ ] K 线 5 分/15 分/小时/日/周/月周期标签有解释
- [ ] 所有小字和关键数字在真机可读

## 七、审核材料

- [ ] 营业执照清晰原件扫描
- [ ] ICP 和 APP 备案完成
- [ ] 软件著作权证书或华为认可的替代材料
- [ ] EDI 主管部门意见/许可证（如需要）
- [ ] 资金路径和支付边界与实际一致
- [ ] 华为已确认现实企业服务交易的支付/IAP适用范围
- [ ] 四类审核账号可用，密码只放私密字段
- [ ] 审核步骤、测试数据和测试支付说明完整
- [ ] 图标、宣传图、手机/平板截图为最终版本
