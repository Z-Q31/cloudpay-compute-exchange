# CloudPay 华为支付/IAP 适用范围咨询稿

用途：通过 AppGallery Connect 工单或开发者支持渠道，确认企业现实服务订单是否必须使用华为应用内支付，以及审核所需证明。

## 工单标题

咨询 CloudPay 企业算力服务撮合订单的支付及应用内购买适用要求

## 工单正文

您好：

我司上海申比芯人工智能科技有限公司拟在华为应用市场提交 CloudPay（Android 包名：`com.kaicloud.marketplace`）。

CloudPay 面向企业用户，为企业采购方和已认证企业供应商提供 GPU 算力、具体大模型 Token 调用服务、模型实例容量及柜月等现实企业服务的展示、询价撮合、容量预留、交付、计量、验收和对账管理。

本应用不销售游戏道具、会员数字内容、虚拟币或可流通代币，不提供个人储值钱包、充值、提现、证券、期货或理财服务。第三方供应商订单拟由企业采购方向订单列明的供应商对公账户支付算力服务款，供应商向采购方开具算力服务发票；CloudPay 另向供应商收取平台技术服务费并开具相应发票。平台自营资源订单由我司作为卖方收款、开票和交付。

现咨询：

1. 上述企业现实算力服务是否属于华为应用内支付必须覆盖的数字内容或数字服务范围；
2. 如不要求使用华为应用内支付，审核时需提交哪些订单、合同、发票、资金流或业务说明；
3. 应用能否展示对公转账付款指引，并在后台核验银行入账后更新订单状态；
4. 若后续接入银行或持牌支付机构，需在 AGC 或应用审核中补充哪些配置和材料；
5. 平台自营算力与第三方供应商撮合商品是否需要在页面或提审材料中分别标注。

我们会按照贵方书面答复调整支付页面、商店声明和审核材料。烦请告知适用政策条款及建议提交方式。
